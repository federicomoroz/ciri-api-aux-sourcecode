n8n y la API
quién le pide qué a quién

Cada paso del razonamiento es un nodo visible en n8n, y cada dato que ese razonamiento necesita es una llamada con nombre a la API. n8n decide el orden; la API ejecuta y es la única que toca el mundo exterior — la base, el vector store, el modelo. Por eso una investigación se puede auditar leyendo el canvas.

Ningún umbral vive en el canvas

Los plazos de SLA, los ratios de contracargo y las reglas de reincidencia se consultan a la API, que los lee de domain/constants.py. n8n no sabe cuánto es «mucho».

No hay nodo de agente

Ningún modelo elige qué herramienta llamar. Las quince llamadas están escritas de antemano y siempre en este orden. Cuáles corren depende del caso: con informe en caché terminan dos, y las tres del tramo HITL sólo cuando hace falta una persona. Eso es lo que hace reproducible una investigación.
