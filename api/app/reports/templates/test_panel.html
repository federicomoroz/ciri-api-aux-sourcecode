Modelo por paso

El pipeline hace tres llamadas y cada una es una tarea distinta. Aplicar vale para tu sesion y no le cambia nada a nadie mas; Guardar como predeterminado cambia el servidor, que es lo que usa n8n. Las claves no se guardan: van en el campo de arriba, o el servidor pone las suyas para los proveedores con free tier.

opcional

Tiene que ser una URL PUBLICA —n8n Cloud, por ejemplo—: al webhook lo llama esta API, no tu navegador. Un n8n en tu maquina no le es alcanzable; para ese caso, levanta el proyecto con docker-compose y usa su panel. Dejalo vacio para usar el pipeline directo.
